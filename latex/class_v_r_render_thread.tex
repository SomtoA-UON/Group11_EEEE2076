\doxysubsection{Detailed Description}
Runs the Open\+VR renderer in a separate thread from the main Qt GUI.

Actors should be added using \doxylink{class_v_r_render_thread_a17bb943e3b852339398cfbb7cb12cf13}{add\+Actor\+Offline()} before the thread is started.
